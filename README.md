# Pokémon Mystery Dungeon: Red Rescue Team - Shiny Patch+

A quality life expansion of the Red Rescue Team Shiny Patch by jtjanecek and the other rogue rescue team devs (base shiny patch here: https://github.com/jtjanecek/rogue-rescue-team/releases/tag/shiny-patch-v1.0.0). This patch is built upon their work and is not meant as a replacement, but as a customizable quality of life experience for shiny hunting rescue teams.


Base shiny patch features:
- Shinies for every available pokemon
- Exclusive pokemon from both red and blue rescue team are present
- Soft reset button combo
- Auto-pilot
- All friend areas are granted from the start for immediate recruiting
- Removed recruit logic gates preventing you from recruiting while in “Refugee Arc”
- Boss Rematches (Skarmory, Team Meanies)
- Add Base Change option in mailbox after Mankey Storyline
- Add renaming ability in Friend Areas
- Pick any player and partner or use vanilla personality quiz
- Changed recruit rates so that all pokemon are recruitable


Additional shiny patch+ features:
- The Wigglytuff club is now an in-game configuration menu for some shiny patch+ features
- Customizeable shiny rates; select from three presets or set your own shiny rates via the Wigglytuff club
- Setting to maintain the first three members of your dungeon party between days
- Setting to disable the waiting action once the floors turn count has entered the "Something is stirring" phases to prevent ejects when shiny hunting
- Setting to allow for only shiny pokemon recruitment
- Removed party body size limit
- Added start button confirmation to the "a shiny is on this floor" notification to prevent oversight while waiting
- Auto-pilot disables when leader hunger is at 1/100 to prevent auto-pilot hunger deaths
- Removed Jirachi wish option to receive a friend area as all are immediately obtained in this hack
- Added Jirachi wish to convert your starter and partner pokemon to shinies

FAQ:
Q: Is this patch save safe with saves from the original shiny patch?
- Yes, simply make a save back-up, load the save with this patch and set your settings with Wigglytuff

Q: Can I hunt for shinies with save-states?
- Save-states will not provide additional benefits. Normal dungeon mons will spawn the same unless different actions are performed after loading the save-state. Legendary mons shiny status are determined when loading the dungeon, or loading the last portion of the dungeon for dungeons that have intermediate save points

Q: Am I missing shinies?
- No. Non-legendaries will always cause a notification when they spawn. Legendaries will not, but all shinies, including legendaries are guarenteed to offer to join your rescue team

Q: Can starters/partners be shiny?
- Yes

Q: How do Latios and Latias work?
- Both of their shiny status is set when entering Northern Range. If Latios is shiny in the boss fight, both will be when you recruit them. If Latios is not shiny in the boss fight you would need to restart Northern Range to reattempt

Q: Will these features be incorporated into the main shiny patch?
- All are available to be pulled into the main patch, but which features would be included is at the disgression of the main devs
